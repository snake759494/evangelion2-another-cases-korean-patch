# 신세기 에반게리온 2 -만들어진 세계- (PSP) 한글패치 v1.2

『新世紀エヴァンゲリオン2 造られしセカイ -another cases-』(ULJS00064)용 비공식 한국어 패치입니다.

## 적용
```
xdelta3 -d -s "Shin Seiki Evangelion 2 - Tsukurareshi Sekai - Another Cases (Japan).iso" Eva2_AnotherCases_KR_v1.2.xdelta "Shin Seiki Evangelion 2 - Tsukurareshi Sekai - Another Cases (Japan) [KR].iso"
```
| | 크기 | MD5 |
|---|---|---|
| 원본 ISO | 891,191,296 | 4953ebbb73de0e868191a3b1d72e25e7 |
| 결과 ISO | 891,906,048 | 58d3e105e60a62f0270ca9f51d690a16 |

- 복호화한 EBOOT(평문 ELF)를 넣었기 때문에 PPSSPP·커스텀 펌웨어에서 동작하며, 정품 펌웨어에서는 부팅되지 않습니다.

## 번역 범위
- 대사·시나리오·이벤트 스크립트 34,210문장, 실행 파일 내 메뉴·아이템·인물·행동 문자열 4,423개, 전투 대사(btimtext)
- 이미지 590종(중복 사본 포함 1,473곳): 전체 화면 자막 카드(에피소드 제목·인물 소개·사도 소개), 간판 일부, 타이틀·메뉴, 시나리오 선택, 장면 자막 카드(에피소드 제목), 상태·아이템·인간관계·편의점 화면, 전투 UI, 이벤트 문구 카드
- 용어는 국내 방영판 기준: `translation/GUIDE.md`

## 폰트
- 게임이 쓰는 PSP 시스템 폰트(jpn0.pgf, FTT-NewRodin DB) 대신 전용 PGF 폰트(`USRDIR/kfont.pgf`)를 읽게 했습니다. 한글은 **나눔스퀘어네오 Bold** 17px, 가나·기호는 원본 글리프.
- 이미지: 명조풍은 **서울한강체**, 고딕풍은 **나눔스퀘어네오**.

## v1.2 변경
- 한글 글자 아래쪽이 잘리던 문제 수정
- 빠졌던 실행 파일 문자열(옵션 항목, 버튼 안내 등)과 전투 대사 파일 번역 반영
- 전체 화면 자막 카드 317장 등 이미지 추가 한글화, 폰트 기호 범위 확장

## 알려진 한계
- 다른 문자열과 꼬리를 공유하는 실행 파일 문자열 73개는 일본어로 남습니다.
- 타이틀 로고의 가타카나, 스태프롤 이미지, 배경 그림 속 간판·문패는 원본 그대로입니다.
- 시나리오 선택 인물 그림 위의 이름을 지운 자리에 약간의 번짐이 있습니다.
- 반각 띄어쓰기가 게임 특성상 약간 넓게 보입니다.
- PPSSPP에서 부팅·메뉴·시나리오 선택·서장 대사까지 확인했습니다. 전체 진행과 실기는 검증하지 않았습니다.
