# 신세기 에반게리온 2 -만들어진 세계- 번역 지침

입력: `translation/batches/bNNN.json` — `[[id, 일본어], ...]`
출력: `translation/out/bNNN.json` — `{"id": "한국어", ...}` (UTF-8, 모든 id 포함, id는 문자열 키)
검증: `python tools/check.py bNNN` — 오류가 0이 될 때까지 고친다.

배치 안의 문장은 게임 속 순서대로 이어져 있다(같은 장면의 대사가 연속). 앞뒤 문맥을 보고 화자·말투를 일관되게 옮긴다.
같은 대사가 화자별로 조금씩 다른 변형(예: 미사토/겐도/리츠코 버전)으로 연달아 나오는 경우가 많다. 각 변형의 말투 차이를 살린다.

## 절대 규칙
1. 제어코드는 **글자 그대로, 같은 개수로** 남긴다: `$x` `$m` `$n` `$d` `$f` 등 `$`+영문 소문자, `%1i` 같은 `%`코드, 페이지 대기 기호 `▽`.
   - `$d`는 숫자 변수(예: `第$d使徒` → `제$d사도`), `%1i`는 버튼 아이콘(`%1i버튼을 눌러` → `%1i 버튼을 눌러`).
   - `$m` `$n` `$x` `$f`의 위치는 원문과 같은 자리(대개 줄 끝/문장 앞)에 둔다.
2. 줄바꿈 `\n`: 원문이 `\n`으로 끝나면 번역도 `\n`으로 끝낸다. 줄 수는 원문과 같게(원문이 1~2줄인 대사는 1줄 더 써도 됨).
3. **한 줄 폭은 한글 17자 이하** (반각 영문·숫자·공백·!?,. 는 약 0.3~0.8자). 원문 줄이 더 길면 원문 길이까지 허용. 넘치면 줄을 다시 나누거나 표현을 줄인다.
4. 일본어(가나·한자)를 한 글자도 남기지 않는다. 전각 영숫자(ＯＫ, ３)는 반각(OK, 3)으로 써도 된다.
5. 쓸 수 있는 문자: 한글, 반각 영문/숫자/기호, `…・「」『』（）～♪☆★○●◎◇◆□■△▲▽▼※→←↑↓、。！？：／－＋％×＝【】《》〈〉―`. 문장부호는 한국어식으로 `!` `?` `,` `.` (반각)을 권장, 말줄임은 `…`.
6. `ΑΤ`(그리스 문자)는 AT 필드의 AT다 → `AT`로 쓴다 (`ΑΤフィールド` → `AT 필드`).
7. `／`로 구분된 문자열은 선택지 목록이다. 구분자 `／` 개수를 유지한다.
8. 문장 끝 `。`는 `.`로. `、`는 `,`로. 단 원문에 없던 말줄임을 새로 만들지 않는다.
9. 말투: TV판 국내 방영(투니버스) 느낌의 자연스러운 한국어 구어.
   - 신지: 소심한 존댓말/반말 섞인 소년. 미사토에게 "미사토 씨"(존댓말).
   - 아스카: 도도하고 거친 반말, 신지를 "바보 신지", "바보"(バカシンジ). "あんたバカぁ？" = "너 바보야?"
   - 레이: 짧고 담담한 말투.
   - 미사토: 밝은 누나 말투, 작전 중엔 단호한 명령조.
   - 겐도: 짧고 위압적인 명령조("~해라", "문제없다").
   - 토우지: 간사이 사투리 → 경상도 사투리 느낌의 거친 말("~하나?", "~데이", "와 이라노").
   - 카오루: 부드럽고 시적인 말투.
   - 펜펜 울음소리 "クワァ" 등은 "꽈악" 식으로 옮긴다.

## EBOOT 문자열 배치 (eNNN)
입력: `translation/batches/eNNN.json` — `[[오프셋, 일본어, 최대바이트], ...]`
출력: `translation/out/eNNN.json` — `{"오프셋": "한국어", ...}` (오프셋 숫자를 문자열 키로)
검증: `python tools/check_e.py eNNN`
- 실행 파일 안의 고정 크기 칸에 덮어쓰므로 **바이트 수 제한**이 있다: 한글·전각 기호 1자 = 2바이트, 반각 영숫자·공백·!?,. = 1바이트. 제한을 넘으면 줄이거나 약어를 쓴다.
- 메뉴·아이템명·설명·인물명·장소명·행동 선택지·일기(로그)용 문장 조각 등이 섞여 있다. 앞뒤 항목을 보고 용도를 추측한다.
- **문장 조각**(예: `に、使徒について`, `〜したこと`, `の愚痴に対して`)은 런타임에 다른 조각(인물명 등)과 이어 붙는다. 한국어 어순이 완벽히 맞지 않더라도 앞뒤 조각과 이어졌을 때 최대한 자연스럽도록, 조사로 시작하는 조각은 `에게`, `와(과)` 처럼 옮긴다. 조각의 앞뒤 공백 유무를 원문과 같게 유지한다.
- `%s` `%d` `%-5D` `%2d` 등 서식 코드는 순서·개수 그대로 둔다.
- 앞쪽 전각 공백(`　`)으로 정렬한 인물명(`　　碇ゲンドウ`)은 전각 공백 대신 반각 공백으로 비슷한 정렬을 해도 된다(바이트 제한 안에서).
- 디버그용으로 보이는 문자열(`[model] ...`, `eva:...`, `デバッグ` 등)도 짧게 번역한다.
